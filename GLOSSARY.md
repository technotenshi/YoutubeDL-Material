# YoutubeDL-Material fork

A fork of Tzahi12345/YoutubeDL-Material, kept in step with the original project while carrying its own changes.

## Language

**Upstream**:
The original project, Tzahi12345/YoutubeDL-Material, and specifically its `master` branch.
_Avoid_: Original repo, parent, source

**Upstream sync**:
Bringing new commits from Upstream into the fork so that Upstream's own commits remain in the fork's history.
_Avoid_: Update, pull, mirror

**Checkpoint**:
The Upstream commit last verified as fully included in the fork. Anything on Upstream after it has not been reviewed.
_Avoid_: Baseline, pin, last sync
